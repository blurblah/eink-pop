# eink-pop

LILYGO 4.7인치 e-paper와 ESP32-S3를 이용해 Prince of Persia의 플레이 가능성을 검증하는 개발 프로젝트입니다.

첫 하드웨어 검증과 제한된 흑백 애니메이션 1회 시험을 완료했습니다. 전체 16MB 출고 펌웨어 백업을 보존한 상태에서 사각형 12프레임이 약 24초에 종료됐고, 사용자가 이동과 종료 후 깜빡임·잔상 없음을 확인했습니다. 갱신 중에는 큰 영역의 심한 깜빡임이 관찰돼 현재 방식은 게임용으로 개선이 필요합니다. 제조사 지연 함수 결함도 발견했으며 추가 장치 실행 전 수정·검증이 필요합니다.

## 프로젝트의 역할

제품 용도, 휴대성, 화면 비율, 버튼 배치, 부품 구매와 비용 판단은 기존 기획 대화에서 다룹니다. 이 프로젝트에서는 펌웨어, Mac 프로그램, SDLPoP 연동과 실측 결과를 관리합니다. 실측 결과를 기획 대화에 전달해 다음 개발 여부를 결정합니다.

초기 구성은 다음과 같습니다.

```text
Mac 키보드 → Mac의 SDLPoP → USB 화면 전송 → ESP32-S3 → e-paper
Mac 스피커 ← 게임 오디오
```

USB 화면 전송은 앞으로 구현할 기능입니다. 현재 보드는 USB에 연결하면 자동으로 Mac의 모니터가 되는 제품이 아닙니다.

드라이버는 `repos/LilyGo-EPD47`, 게임은 `repos/SDLPoP`에서 개발합니다. 각각 작업 브랜치를 만들고 상위 프로젝트에 submodule로 등록했습니다. SDLPoP의 기존 `<strings.h>` 수정도 새 브랜치에 커밋했으며 `/Users/blurblah/workspace/SDLPoP` 원본은 그대로 보존했습니다. 모든 관련 변경은 로컬 커밋으로 남기고 push하지 않습니다.
