# eink-pop

LILYGO 4.7인치 e-paper와 ESP32-S3를 이용해 Prince of Persia의 플레이 가능성을 검증하는 개발 프로젝트입니다.

첫 하드웨어 검증과 초기 흑백 애니메이션에 이어 제조사 지연 함수 결함을 수정했습니다. 두 호출을 사용하는 차분 시험은 큰 영역 깜빡임을 거의 없앴고 12프레임을 약 12.2초에 마쳤습니다. 약간의 잔상과 이동 중 좁아짐이 남았으며 마지막은 정사각형으로 멈췄습니다. 전체 16MB 출고 펌웨어 백업은 보존했습니다.

후속 교차 갱신 시험에서는 좁아짐이 줄었지만 일부가 따로 구분돼 보였고 잔상은 조금 더 심해졌습니다. 후속 프레임 처리도 약 682ms에서 714ms로 늘었습니다. 큰 영역 깜빡임 없이 정상 종료했지만, 전반적인 개선을 확인하지 못해 교차 방식을 다음 단계의 기본값으로 채택하지 않습니다.

다음 단계로 SDLPoP의 최신 화면 추출, Mac의 USB 전송기, ESP32의 제한 수신·차분 출력 경로를 구현했습니다. 전체 정리로 사각형 잔상이 사라지는 것을 확인한 뒤 실제 게임 화면 한 장을USB 흑백으로 표시했습니다. 변환의 명암 손실을 확인해 별도 정지 이미지 펌웨어로 실제16계조 한 장을 출력했고, 사용자는 생명력 화살표를 제외하면 훌륭하다고 평가했습니다. 이후 생명력과 중간톤 보정도 사용자가 확인했습니다. 같은 변환을 실제 게임의 최신 화면에 적용한 USB v2로 서로 다른 12장을 정상 처리했습니다. 다만 사용자는 전체 검정 깜빡임 때문에 이동 느낌 없이 정지 화면만 잠깐 보인다고 평가했습니다. 현재 매 프레임 전체 지우기 후 16계조 방식은 게임 플레이에 부적합합니다.

## 프로젝트의 역할

제품 용도, 휴대성, 화면 비율, 버튼 배치, 부품 구매와 비용 판단은 기존 기획 대화에서 다룹니다. 이 프로젝트에서는 펌웨어, Mac 프로그램, SDLPoP 연동과 실측 결과를 관리합니다. 실측 결과를 기획 대화에 전달해 다음 개발 여부를 결정합니다.

초기 구성은 다음과 같습니다.

```text
Mac 키보드 → Mac의 SDLPoP → USB 화면 전송 → ESP32-S3 → e-paper
Mac 스피커 ← 게임 오디오
```

USB 화면 전송은 이 프로젝트의 전용 게임 추출기·호스트 프로그램·펌웨어를 통해 동작합니다. 첫 시험은 1장, 후속 시험도 최대 12장으로 제한하며 USB에 연결하기만 해서는 화면이 갱신되지 않습니다.

## 다음 작업

보드 반복 시험을 줄이기 위한 [오프라인 분석 도구](docs/오프라인-화면-분석.md)를 추가했습니다. 기존12장의 재생·변화 분석과 실측 범위 내 시간 추정을 제공하며, 250ms 대기 제거만으로는10fps에 도달하지 못함을 확인했습니다. 관련18개 테스트와 브라우저 동작 검증을 통과했습니다. 후속 내장 데모28초에서 이동·점프·방 전환·전투315장을 비교했습니다. 세 흑백 방식 중 속도 개선을 입증한 후보는 없으며, 넓은 변화 영역은 기존 시간 모델 밖임을 확인했습니다. 후보 비교9개 테스트와 브라우저 검증도 통과했습니다. 현재 도구는 잔상이나 깜빡임을 예측하지 않습니다.

앞선 [4bpp 연동 계획](.Codex/plans/PLAN-20260920-0347-live-gray-game.md)은 12장 전송에 성공했지만 처리 간격 약2.33초와 매번 전체 지우기의 검정 깜빡임으로 플레이에 부적합했습니다. 게임 실행 보드를 바꿔도 남는 화면 구동 문제이므로, 사용자 승인에 따라 [흑백 차분 계획](.Codex/plans/PLAN-20260927-1827-live-game-delta.md)을 진행했습니다. 현재 코드는 USB v3·고정 점무늬 흑백이며 최초 정리 뒤 바뀐 픽셀만 구동합니다. 호스트29개·펌웨어47개 검증과 ESP32 빌드를 통과했습니다. 실제 게임12장 시험도 정상 종료했고, 첫 화면 이후 전체 지우기0회·후속 처리 평균0.687초·호출 간격1.015초를 확인했습니다. 사용자는 위치 변화는 나아졌지만 순간이동처럼 끊기고 깜빡임도 있었던 것 같다고 평가했으며 도트 표현으로 바뀐 이유를 질문했습니다. 부드러운 게임 움직임을 달성하지 못했고 잔상·생명력 관찰은 미확인입니다. 게임과 패널 구동은 종료했고 현재 결과는 [검증 문서](docs/게임-차분-갱신-검증.md)를 따릅니다.
