# 작업: NORMAL 압축 입력의 제한 실시간 게임 연결

| 항목 | 내용 |
| --- | --- |
| 상태 | 실행 중 — 기존 게임 연동·연속 진행 승인 범위 |
| 위험도 | 중간 — 새 USB 수신 앱, 같은 검증된 H716 구동 |

## 요청 사항

NORMAL 압축 입력의 화질과 시간 개선을 유지하고, 녹화 프레임을 늦게 모두 재생하는 대신 실제 게임의 최신 화면을 보낸다. 게임 실행·입력은 기존 Mac SDLPoP에서 담당한다.

## 성공 조건

- [x] 남은 시간 비용과 기록 재생/최신 화면 정책의 차이를 문서로 구분한다.
- [x] EPK1 패킷 구조·CRC·세션·순서를 재사용한 v4/2bpp 전용 수신 앱과 호스트를 구현한다. 기존 v3 앱·호스트는 그대로 보존한다.
- [x] FRAME CRC 확인 전 패널 무접근, 최대12장·30초·수신5초 한도, 오류/STOP/완료에서 드라이버 idle 확인 및 OFF를 검증한다.
- [x] 호스트가 ACK 후 파일을 새로 읽고 대기 프레임을 쌓지 않으며 CRC/순서/DONE/OFF/10초 무출력을 엄격히 확인한다.
- [x] native·호스트 검증 및 ESP32 빌드·백업·로컬 커밋을 확인한다.
- [ ] 정리·업로드 뒤 게임 창으로 전환할 시간을 예고하고 실제12장만 실행한다. 광학 관찰·입력 지연·로그를 구분 기록한다.

## 가정 및 제약

드라이버7544e2d·NORMAL/direct/profile=0 및 v7의 동일2bpp 확대·밝기 변환을 사용한다. 파형·전압·핀·대기는 변경하지 않는다. 약4.74장/초는 이전 Flash 재생의 소프트웨어 수치이며 USB 전송/변환 지연이 추가된다. 게임 로직을 늦추지 않으며 표시하지 못하는 중간 화면은 건너뛴다. 제조사 초기 정리 한 번은 기존 검증 앱으로 수행한다.

## 영향 범위

- firmware/painter_usb/painter_usb.ino: 기존 수신 상태 머신과 검증된 Painter 라이프사이클 조합.
- host/painter_usb.py: 기존 SerialIO·PPM 형식·4명도 변환을 재사용하는 제한 전송.
- tests/test_painter_usb_firmware.py, tests/test_painter_usb_host.py: 상태·오류·화면·최신 프레임 선택·종료.
- 문서·계획, .local/artifacts의 빌드·실행 기록.

## 실행 계획

- [x] 1. 프로토콜/수명 계약과 최신 프레임 정책 확정 → 구형 호스트의 오접속 거부.
- [x] 2. 펌웨어·호스트 구현 → 패킷·원본·전체 픽셀·오류·한도·종료 검증.
- [x] 3. 빌드·복구 확인·커밋 → 제조사 정리 및 READY까지만 업로드.
- [ ] 4. 관찰 예고·최대12장 실시간 입력 → ACK/CRC/OFF/10초·실물 확인 및 커밋.

## 위험 및 롤백

구형v3와 구분되는 v4 패킷과 PAINTER_USB 마커를 사용한다. 파싱 오류는 재시도 없이 종료한다. 호스트 실패 시 다운로드 정지하며 자동 반복하지 않는다. 버퍼는 초기화·할당 실패를 검사하고 실제 출력 완료 이후만 해제한다. v7 녹화 앱·제조사 복구 앱·출고 백업을 보존한다. SDLPoP가 시작한 프로세스만 종료하며 기존 사용자의 게임 프로세스는 건드리지 않는다.

## 실행 기록

- 드라이버 소스 분석: 19주사×4ms=76ms는 회색 파형 조건, 임의 제거 보류. 느린 순차 녹화 대신 ACK 후 최신PPM 선택을 구현.
- 실제 수신 스케치31사례 ASan/UBSan·호스트8테스트(오류16종 포함) 통과. ESP32 앱331568바이트 SHA-256 54586efbfef6521c669c1678dbb7142d4a550ee258274c235523dd15b39a463f. 하드웨어 업로드 전.

- 2d5d856 커밋 후 제조사 정리 한 번·새앱 단일 업로드·READY 확인. 새 게임 자식 실행·60초 전환 시간 뒤 최신 화면12장 전송 성공. 원본749→791 중3~4장씩 선택,192313바이트/CRC/ACK·clear최초1회·각1주기·DONE12/OFF·10.003296초 무출력 확인. 게임 정상종료code0·강제종료/임시PPM 없음·포트 닫힘.
- 후속 display196.208ms·ACK 간격292.171ms(소프트웨어3.42장/초). 다른 장면이라 이전 녹화 드라이버 속도와 직접 비교하지 않음. 실물 조작/움직임/잔상 관찰만 대기 중이며 화면 유지.
