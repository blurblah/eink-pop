## 가정 및 제약

- 기성 보드와 보유한 작은 브레드보드로 시제품을 만든다. Pi Zero 2 W는 미보유이며 구매 후보다. 충전 가능, 방향키 4개·동작 2개·Reset·Select·Start 및 전원 ON/OFF가 요구사항이다. 사용자는 초기3~4시간 목표보다 얇고 작은 배터리를 우선하며 약2시간으로 낮춰도 좋다고 수정했다. 예산·최대 외형·내장 스피커·충전 중 플레이 필수 여부는 미정이다.
- 기존 H716 화면 보드 유지 구성은 최소 변경을 위한 후보이며 확정 설계가 아니다.
- 원본 `/Users/blurblah/workspace/eink-pop/docs/보드-제작-인계.md`를 읽기 전용으로 참조했다. 인계 커밋은 `9738053`, 이 worktree의 시작점은 `374ec38`이다. 현재 worktree README의 미구현 표시는 최신 상태가 아니다.
- 최신 구성은 Mac 게임·입력·오디오·RGB→4명도 변환 → USB v9 → ESP32-S3 H716이다. 실물은 `Screen-4.7-S3 V2.4 2024-12-03`이다.
- 표시 기준C 및 잔상 문제는 원본 화면 작업에서 관리한다. 실행부 변경으로 광학 문제가 해결된다고 가정하지 않는다.
- 원본 파일·브랜치, 별도 SDLPoP 저장소, submodule은 변경하지 않는다. USB 열기·리셋·플래시·게임 실행·기존 세션 종료를 하지 않는다.
- 실제 이식 전 로컬 전용 submodule 커밋을 보존하는 별도 소스 확보 절차를 구체화한다. 원격 강제 갱신으로 대체하지 않는다.
- 구매·PCB 발주 전에는 부품번호·수량·배송 포함 견적·회로·검증 결과를 구체화해 승인받는다. 이 계획은 구매나 장치 조작 승인이 아니다.
- 변경은 현재 작업 브랜치에 로컬 커밋하며 push하지 않는다. 계정 잔여 55% 미만이면 중단한다.

## 최소 제작 후보

`물리 버튼 → 소형 Linux 실행부 → 기존 USB 전송 → H716 화면 보드`

`Linux 실행부 → 오디오 출력 모듈 → 스피커`

처음에는 외부 전원으로 검증하고, 측정한 소비전력에 맞춰 배터리·충전·전원 경로를 선정한다.

| 부분 | 우선 검토안 | 확정 전 확인 |
| --- | --- | --- |
| 실행부 | Raspberry Pi Zero 2 W + microSD | SDLPoP·변환기 ARM Linux 빌드, 화면 모니터 없이 렌더링·프레임 추출, CPU·메모리·부팅 시간 |
| 표시 연결 | Pi USB 호스트에서 기존 H716 USB 입력 유지 | OTG 케이블, 장치 열기 때 리셋 여부, v9·ACK·재연결, 전체 전류 예산 |
| 입력 | 방향 4개 + 동작 2개 + Reset·Select·Start = 9개 | 개별 GPIO 입력 우선 검토. 동시 누름, 대각선 점프·매달리기·전투·메뉴 조작, 손 크기와 버튼 간격 검증; Reset은 게임 재시작 후보로 강제 전원 리셋과 구분 |
| 오디오 | 내장 스피커 요구 시 I2S 앰프 모듈 후보 | 제조사 핀·전압·드라이버, 버튼 GPIO와 충돌, 스피커 임피던스·출력·볼륨·잡음 |
| 전원 | 외부 안정화 전원으로 먼저 검증 | Pi와 화면·오디오를 합친 평균·피크 전력; 화면 보드 확장 전원으로 Pi를 구동하지 않음 |
| 배터리 | 실측 이후 보호·충전·승압 구성을 선정 | 목표 시간, 충전 중 사용 시 전원 경로 관리, 저전압 종료·안전 종료, USB와 별도 급전 간 역급전 방지 |
| 기구·PCB | 배선 시제품 후 배치·두께 검증 | 화면 외형과 커넥터·배터리·스피커·버튼을 합친 실치수; 맞춤 PCB 요청 시 버튼/연결 기판부터 검토 |

Pi의 크기와 SDLPoP의 Linux 지원은 공식 근거다. 이 조합에서의 게임 성능·USB 호환성은 아직 실측하지 않았다. 게임 자체를 ESP32로 이식하는 경로는 별도 이식량이 필요하므로 최소 제작 후보에서 제외했다.

## 공식 근거와 로컬 확인

- [Raspberry Pi Zero 2 W 공식 사양](https://www.raspberrypi.com/products/raspberry-pi-zero-2-w/): 65×30mm, 1GHz 4코어, RAM 512MB, microSD, micro USB OTG, 미실장 40핀 헤더. 공급사 판매가·국내 재고·총 구매 비용은 미확인.
- [SDLPoP 공식 저장소](https://github.com/NagyD/SDLPoP): Linux에서 SDL2·SDL2_image로 빌드하는 절차와 방향키·Shift·게임패드 조작 안내. 특정 Pi에서 현재 수정본이 검증됐다는 근거는 아니다.
- [Raspberry Pi 하드웨어 문서](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html): 부품 선정 시 GPIO·USB·전원 조건 재확인용.
- [LILYGO 제품 안내](https://lilygo.cc/products/t5-4-7-inch-e-paper-v2-3), [정확한 V2.4 회로도](https://github.com/Xinyuan-LilyGO/LilyGo-EPD47/blob/esp32s3/schematic/Screen-4.7-S3-V2.4%202024-12-03.pdf): 제품 페이지를 확인했으나 이번 단계에서 회로도 전원 경로·핀 단위 호환성은 검증하지 않았다. 다른 리비전의 사양을 대입하지 않는다.
- 원본 `repos/SDLPoP/src/Makefile`은 SDL2·SDL2_image 사용 및 Darwin 조건 분기를 포함한다. `host/painter_native.py`에는 비macOS용 `.so` 빌드 분기가 있다. `host/usb_frame.py`는 termios와 DTR/RTS 제어를 사용하므로 Linux 실물 연결 검증이 필요하다. 코드를 읽었으며 실행하지 않았다.

## 시제품 부품 선정 검토

- Pi Zero 2 W는 320×200 SDLPoP와 C 변환기 기반 구성에 유력한 후보다. 공식 Linux 지원과 하드웨어 사양에 따른 판단이며 현재 수정본의 ARM 실측 결과는 아니다. RAM 512MB이므로 가벼운 OS와 게임 전용 실행을 우선한다.
- 버튼 9개를 개별 GPIO와 GND에 연결하고 내부 풀업·디바운스를 적용하는 구성을 검토한다. OS 종료 버튼을 별도로 두면 총10개이므로 여분 포함 택트 스위치20개가 적절하다. 핀 배치는 구현 계획에서 확정한다.
- 브레드보드는 입력 실험에 쓰고 Pi·화면·앰프의 주 전류는 전원 케이블로 공급한다. 작은 브레드보드에 버튼을 모두 배치할 수 있는지는 실치수 확인이 필요하다.
- 10000mAh 보조배터리는 사용자의 크기 우선 요구에 따라 휴대용 구매안에서 제외한다. 얇은1셀3.7V 리튬폴리머2500~3000mAh와 별도 충전·승압·전원관리 보드를 우선 비교한다. 배터리와 Pi를 화면 뒤에 나눠 배치하는 안을 검토하되 실치수와 기존 화면 PCB 간섭 확인 전 두께를 보장하지 않는다.
- 배터리 계산 예: 3.7V2500mAh에 승압효율85%를 가정하면 약7.86Wh이며 전체 평균3W/4W일 때 약2.6/2.0시간이다. 3000mAh이면 약9.44Wh, 같은 조건에서3.1/2.4시간이다. 효율과 부하는 실측값이 아닌 비교 시나리오이며 노화·종료 여유가 추가로 필요하다. 2시간에20% 여유를 두면2500mAh은 평균약3.1W,3000mAh은약3.8W 이하여야 한다.
- PiSugar3 Air는 외장1셀 배터리·충전·전원 버튼·소프트웨어 전원관리를 통합하는 후보이나, [공식 기술 문서](https://docs.pisugar.com/docs/product-wiki/battery/pisugar3/pisugar-3-series)의65×30mm/5V2.5A와 [공식 판매 페이지](https://www.pisugar.com/products/pisugar-3-air-portable-power-management-board-for-raspberry-pi-zero-battery-free-version)의65×56mm/5V3A 표기가 상충한다. 정확한 판매품 리비전·실치수를 확인하기 전 확정 구매 보류. 배터리 없이 충전기만으로 동작하지 않는다는 판매 안내도 확인했다.
- [DFRobot DFR0446](https://www.dfrobot.com/product-1613.html)은35×30mm,1셀 충전·5V최대2.5A 승압,공식표시$8 후보이다. 안전 종료·출력차단 버튼은 통합되지 않은 별도 설계 항목이며 배터리 허용 충전전류·과방전 보호·커넥터 극성·저전압 피크부하 조건 확인 전 확정하지 않는다.
- [Raspberry Pi 공식 전원 안내](https://www.raspberrypi.com/documentation/computers/getting-started.html)의 Zero 계열5V2.5A는 공급장치 권장 사양이며 실제 상시 소비전력을 뜻하지 않는다. 화면·오디오 포함 전력 실측이 필요하다.
- [Waveshare UPS HAT (C) 공식 문서](https://www.waveshare.com/wiki/UPS_HAT_%28C%29)는1000mAh 배터리, 완충 시 약1.8A 출력 및 전압 하강 시 출력 감소를 안내한다. 현재 사용시간·전력 목표에 바로 구매 권장하지 않는다.
- 소리가 필요하면 MAX98357A I2S 앰프와4Ω3W 스피커가 후보다. [Adafruit 공식 연결 안내](https://learn.adafruit.com/adafruit-max98357-i2s-class-d-mono-amp/raspberry-pi-wiring)는 GPIO18·19·21과5V·GND를 사용한다. 버튼과 핀을 분리하고 전원 여유를 확보한다. 저가 호환 모듈은 실장·핀 표기를 재확인한다.
- 전원 OFF는 소프트웨어 종료 후 물리 차단하는 두 단계가 최소 시제품안이다. 한 버튼으로 종료·전원 차단·재시작하려면 별도 전원 관리 모듈을 선정해야 한다. 일반 USB 인라인 스위치만으로 안전 종료가 되지는 않는다.
