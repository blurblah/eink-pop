## 요청 사항

추가 톤을 끄고13주사2ms를 유지한 상태에서 전투/방/공주 장면을 먼저 검증한다. 장면마다 정리를 강제하는 것은 보류한다.

## 성공 조건

- [x] 컷신 구분값을 RGB와 원자적으로 전달하고 전환을 추적한다.
- [x] 정상 로딩의1초 정지를 오류로 처리하지 않되 무한 정지는 제한한다. 반복 입력은 명시하고 성능에서 분리한다.
- [x] 같은 원본 RGB로 기본/현재 톤을 비교하고 전투·방·컷신 원본을 보존한다.
- [x] 기본톤·방정리없는 제한 후보를 빌드/검증하고 최종 사용자 확인 준비.

## 가정 및 제약

- 시작 잔여96%,55%미만중단. 새파형/전압/해상도변경없음. 사용자 승인된후속검증범위. 마지막광학확인전성공선언금지.
- 주기30초정리/최대10분6000장/STOP은유지. 짧은비교는정리주기전끝내며첫초기정리는동일하게한다.
- 입력읽기일시정지동안같은입력을1초마다전송해장치수신상한유지,10초진행없으면중단. 반복입력은속도표본에서제외하되전체시간/개수별도보고.
- 기존옵션/프로토콜유지,기본톤기본convert재사용. 로컬커밋/push없음.

## 영향 범위

게임eink exporter/출력호출,host/painter_usb.py·관련검증,실행/캡처도구·문서. 펌웨어구동표변경없음.

## 실행 계획

- [x] 컷신/대기 처리 → 실제 exporter 및호스트경계/STOP/무변경검증.
- [x] 원본장면자동캡처 → 메타데이터/해시/재현성·동일입력톤변환검증.
- [x] 후보빌드·준비 → 동일보드/백업/READY,최종비교준비후필수사용자관찰요청.

## 위험 및 롤백

기본톤도잔상가능. 관찰전전체정리제거를일반해법으로선언하지않음.10초대기는영구멈춤을즉시구분하지못하는제한적유예이며기록한다. 이전옵션/펌웨어·제조사정리복구보존.


## 실행 기록

- 게임 `ea22c44`의 실제 exporter14시나리오/게임 빌드, 호스트29개 검증 통과. 실제 컷신 진입/종료를 확보했고6.166초 출력 공백 뒤2레벨 정상 재개를 확인했다.10초 제한적 대기와 반복 입력 구분을 구현했다.
- 동일 RGB180장씩 기본/현재 톤의 C/Python 결과와 생산 호스트 모의 전송 검증 통과. 컷신 샘플링/원본 정지 시간 생략은 기록했으며 실제 게임 속도 평가로 사용하지 않는다.
- 추가 장면 정리 없는 v8/13주사2ms 앱75f947b0 빌드·업로드 검증, READY/START0. A=현재 톤, B=기본 톤, 각각180장/29초 상한 및 전투 종료3초 관찰. A 뒤 최소60초 유지·제조사 지우기·동일 앱 재업로드 후 B. 주기 정리는30초로 보존하며 비교 중 발생하면 조건 실패.
- 자동 검증과 최종 비교 준비는 완료. 사용자 준비 응답 및 광학 판정 대기이므로 전체 작업은 실행 중으로 유지한다. 잔여95%, 중단선55%미만. 자세한 원본/실행/중단/정리 절차는 성능-개선-반복.md의41회 기록.

- 사용자 준비 응답 후 A/B 각180장 실물 출력 완료, OFF/10초 무출력 확인. 전체 전송 CRC/복원/목표 bitmap 일치, 추가 정리0회. 두 후보 변경 화면 간격 보조 평균은122.863/122.824ms이며 고정 재생·무변경 입력 차이로 실제 게임 성능을 판단하지 않는다.
- 현재 B 마지막 화면/OFF, 최종 광학 평가 대기. 관찰 후 제조사 정리 예정. 사용자 잔상/명암 결과 없이는 품질 개선을 선언하거나19주사 단계로 넘어가지 않는다. 최신 잔여94%.

- 사용자 평가: 두 톤 모두 발·벽돌·무너지는 발판 잔상과 컷신/마지막 장면 밝기 문제. 제조사 최종 지우기1.324068초·OFF 완료. 해결 성공은 아니며 다음 승인 우선순위인19주사 비교는 별도42회 계획으로 이어간다.
