## 요청 사항

> 고정 장면 평가 대신 한동안 직접 플레이하고 이상한 부분이나 중단 시점을 사용자가 이 대화에 남긴다.

## 성공 조건

- [ ] 기존12장/120장 경로를 보존한 별도 세션 식별과 사용자STOP 동작 검증.
- [ ] 최대10분·6000장, 통신5초·구동5초·종료OFF 상한을 확인.
- [ ] 주기 전체정리 구간을 구분하며 명암/파형은13주사2ms·shadow_v1 유지.
- [ ] 사용자 준비 후 게임을 실행하고 중간 평가 질문 없이 직접 조작. 종료 결과·장면 문제·현재 상태 기록.

## 가정 및 제약

- 사용자의 “한동안 플레이하다가…멈추고…여기에 쓸게”는 사용자 종료 방식으로 진행하라는 후속 승인이다. 최대10분 방치 상한을 안내했다.
- 중단 요청 시 정상STOP/OFF, 광학문제 보고 시 마지막 화면을 보존해 기록한 뒤 제조사 정리한다.
- 30초마다 전체 지우기·현재 화면 재표시를 구분 기록한다. 주기의 장기 안전성은 보장하지 않는다.
- 잔여55%미만이면 시작하지 않거나 진행 중 세션을 정상 종료하고 정리한다. 시작61%.
- 기존 게임 원본 보존·로컬커밋/push없음. 새 파형/계조 변경 없음.

## 영향 범위

- 변경: firmware/painter_usb, host/painter_usb.py — 별도v8 START와 사용자중단·시간상한·주기정리.
- 변경: 관련 상태머신/호스트 테스트와 반복문서.
- 재사용: 기존 게임창/전송/제조사 정리 도구와 검증된 드라이버.

## 실행 계획

- [x] 1. 별도 세션·주기정리·STOP 파일 구현 → 기존/새 경계·종료·화면일치 검증.
- [x] 2. 빌드/백업/장치·한도 확인 → 업로드 READY/START0.
- [ ] 3. 준비 후60초 창 전환 시간 제공 → 사용자 중단 또는 상한까지 최신화면 전송.
- [ ] 4. 전체 로그 확인·종료/OFF·최종제조사정리 → 결과와 다음 작업 기록.

## 위험 및 롤백

- 장면별잔상/가독성/누적오차와주기정리깜빡임이 남을수있다. 광학성공을자동수치만으로확정하지않는다.
- 오류/한도/사용자요청으로중단,검증된제조사정리앱으로복구한다.
