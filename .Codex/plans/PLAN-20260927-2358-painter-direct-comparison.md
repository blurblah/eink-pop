## 요청 사항

사용자가 움직임은 훨씬 좋아졌지만 잔상이 꽤 남고 명암이 흐릿하다고 관찰했다. 같은 게임 입력에서 기존 두 주기 경로와 기존 라이브러리의 직접 회색 전이 경로를 비교한다.

- [x] 빌드 선택으로 setDirectTransitions(true)만 활성화하고 실패 시 출력 중단·전원 종료한다. 원래 게임 12장 바이트·밝기 변환·시작 제한·드라이버 소스는 그대로 둔다.
- [x] 실제 스케치의 활성화 시점·실패·출력·종료 회귀와 ESP32 빌드·동일 클립/앱 해시를 확인한다.

## 가정 및 제약

- 직접 표는 작성자의 한 H716 패널에서 측정된 값이며 사용자 패널의 광학 품질·장기 안전성 보장은 아니다.
- 정수 전하 장부는 기존 apply 잠재량 0/4/5/7과 여섯 direct의 차이가 일치한다. 실제 주사 시각·회색 착지·잔상과 별도다.
- 이 클립은 후속 11장 중 10장이 12주사, 1장이 11주사를 필요로 한다. 기존 7+7주사보다 적지만 전송·계산량 차이가 있어 속도 개선을 보장하지 않는다.
- 밝기 곡선 변환 후보는 오프라인에 보존하고 이번 실물 입력에는 적용하지 않는다. 여러 효과를 한 번에 바꾸지 않는다.

## 위험 및 롤백

H716 제공 표를 그대로 쓰며 펄스·전압·표를 임의로 수정하지 않는다. 12장·30초 앱/45초 호스트 한도와 전원OFF를 유지한다. 오류에는 다운로드 모드로 정지한다. 두 주기 앱과 제조사 앱·출고 백업을 보존한다. 직접 방식이 나쁘면 기존 빌드로 되돌린다.

- 6개 직접 표와 apply/remove 장부 일치, 실제 입력의 최대 주사 수 12회(10장)/11회(1장) 확인.
- 실제 스케치 67사례 ASan/UBSan 통과. 초기화·직접 설정 실패 시 프레임 0장·OFF 확인. ESP32 빌드 성공, 앱 SHA-256 e603694a9a08880973a2b0676f4fe1ed0ed23cab76dc1652fe2e6238a512979d. 헤더·클립은 이전 앱과 동일.

- 2203a86 커밋 뒤 제조사 정리 1회·v4 단일 업로드와 READY 확인. 15초 예고 후 GAME 12장 모두1주기로 완료. 주사 수7/12/11, 행 수와 입력 예측 일치.
