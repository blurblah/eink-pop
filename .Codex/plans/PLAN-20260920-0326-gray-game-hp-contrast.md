## 요청 사항

> 실제16계조 게임 화면은 생명력 화살표를 제외하면 훌륭하다. 해당 두 빨간색만 밝은 회색·흰색으로 보정해 보드에 표시한다.

직전 제안과 사용자 승인이 있어 추가 구현 승인을 요청하지 않는다. 단일 출력과 종료 관찰은 기존 한 장 시험을 따른다.

## 가정 및 제약

- 현재 표시 장면·확대·그리기·파형·명령 제한은 유지한다. 헤더의32,000바이트 이미지와식별SHA만 변경한다.
- 점무늬·전체 대비 조정·회색 연속 전송·게임 로직 변경은 포함하지 않는다.
- 이번 이미지는 생명력3칸이 채워진 정지 장면이다. 빈 칸과 깜빡임의 게임동작 실물 검증까지 완료했다고 기록하지 않는다.
- 제공 스킬 목록에 직접 맞는 임베디드 이미지 검증 스킬은 없으며 기존 코드·검증 절차를 사용한다.
