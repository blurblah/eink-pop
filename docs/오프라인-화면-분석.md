# 오프라인 화면 분석

2026-09-27. 보드에 명령을 보내지 않고 기존 v3 송신 기록을 검증·재생하고, 현재 구동 경로의 처리 시간을 추정한다. 패널 입자·잔상·전환 중 깜빡임을 재현하는 물리 시뮬레이터는 아니다.

## 실행

프로젝트 루트에서 Python 3 표준 라이브러리만 사용한다. 입력 원본은 Git에서 제외된 기존 시험 자료다.

```sh
python3 host/offline_display.py \
  --log-prefix artifacts/logs/usb-delta-v3-20260927-play \
  --output artifacts/offline-display-new
```

새 디렉터리에 `index.html`과 `report.json`을 만든다. HTML은 외부 서버·라이브러리 없이 브라우저에서 열 수 있다. 기존 출력 경로는 덮어쓰지 않는다. 입력은 `-tx.bin`, `-observation.json`이며, 정상 종료된 v3 최대12장 기록만 지원한다. 패킷 길이·CRC·세션·순서·이미지 해시·ACK·DONE 수·드라이버와 표시 설정을 대조한다. 펌웨어 바이너리는 로그에서 재검증할 수 없으므로 동일 펌웨어라는 전제가 필요하다.

재생/일시 정지, 이전/다음, 시간축 탐색, 실측 간격과250ms 대기 제거 가정을 제공한다. 저장된 선택 화면만 재생하고 빠진 게임 프레임을 보간하지 않는다. 최초 전체 지우기는 시간축에서 생략하되 처리 시간은 별도로 표시한다. 우측 시간 예산 카드는 입력 세션이 아닌 고정 보정 표본의 평균이다.

## 측정 근거와 결론

드라이버 `f1607dab2df95295e6b50fc0e44c4c092a13938f`, USB v3, 원본320×200·표시640×400·양극성15단계씩의 2026-09-27 단일 시험이다. 보정 표본과 펌웨어 해시는 `host/data/panel_timing_v3.json`에 보존했다. 식별자·원본 이미지·절대 경로는 보정 파일에 포함하지 않는다.

단일 시험 안에서 분할한 오차이며 새 장면·독립 시험의 정확도나 오차 상한이 아니다. 35~97행은 미검증 보간으로 표시하고, 전체 범위 밖과 한 극성만 바뀌는 경우는 예측을 거부한다. 드라이버·파형·온도가 바뀌면 다시 보정해야 한다. 현재 표시 경로의 결과이며 패널의 절대 속도 한계를 뜻하지 않는다.

변화 픽셀이 적어도 행 스캔과 호출 비용이 남으므로 픽셀 수에 비례해 빨라진다고 가정하지 않는다. 320×200의1bpp는8,000바이트, FRAME 패킷은8,024바이트다. 두 원본 비트맵은16,000바이트이며 전체 펌웨어 메모리 사용량은 아니다. 드라이버의 생산자·소비자 실행이 겹치므로 내부 대기 시간을 단순 합산하지 않고 실측으로 보정한다.

현재 수치만으로도 **호스트의250ms 대기를 없애는 것만으로10fps에 도달할 수 없다는 후보 판정**은 가능하다. 잔상·명암·장시간 안전성은 이 모델로 판정할 수 없어 최종 실물 확인이 필요하다.

## 다음 장면의 보드 없는 수집

`host/capture_frames.py`는 이미 실행 중인 게임 추출기의 최신 PPM 파일만 읽는다. 게임을 시작하거나 보드에 접속하지 않는다. 실제 최신 PPM 경로를 지정한다.

```sh
python3 host/capture_frames.py \
  --frame-path /실제/최신/화면.ppm \
  --output artifacts/capture-walk-new \
  --seconds 10 --max-frames 120
```

시간 또는 장수 중 먼저 도달한 조건에서 멈춘다. 최대30초·360장(이미지 약69.2MB)이며 기존 디렉터리는 보존한다. 원자적으로 교체되는 최신 파일을 읽고 같은 번호는 중복 저장하지 않는다. 번호 감소·같은 번호의 내용 변경·잘못된 PPM은 중단하고 수집 명세에 오류를 남긴다. 명세에는 번호·해시·읽은 시각·누락 번호 수를 기록한다. 읽은 시각은 정확한 렌더 시각이 아니다.

이번에는 수집 도구의 합성 입력만 검증했다. 걷기·점프·방 전환의 연속 원본을 새로 수집하지 않았다. 수집한 PPM을 새 변환 후보와 시간 모델에 연결하는 기능은 후속 작업이며, 현재 보고서 CLI는 기존 v3 전송 기록을 입력으로 받는다.

## 검증

```sh
python3 tests/test_offline_display.py
python3 tests/test_capture_frames.py
```

12개 분석 테스트와6개 수집 테스트 통과. 실제 시험12장의96,313바이트 송신 기록에서 보고서를 생성했다. Playwright에서 재생·일시 정지 유지·이전/다음·탐색·대기 제거 시간축·범위 밖 거부·보간 표시를 확인했다. 마지막 캔버스64,000픽셀은 원본 비트맵과 일치했고 JavaScript 실행 오류는 없었다. 전체 화면 캡처로 배치도 확인했다. 검사 탭과 localhost 서버는 종료했다.

최종 로컬 산출물: `artifacts/offline-display-20260927-final/`의 HTML·JSON·검사 캡처. 원본 게임 이미지가 포함되어 Git에서는 제외한다. 이번 작업에서 펌웨어·드라이버·게임 수정이나 업로드·패널 동작은 하지 않았다.
