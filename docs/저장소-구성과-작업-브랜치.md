# 저장소 구성과 작업 브랜치

2026-10-10 사용자 요청에 따라 submodule을 제거하고 같은 폴더 위치의 독립 Git 저장소로 전환했다. 각 저장소에서 일반적인 commit·pull·push를 사용한다.

## 현재 구성

| 저장소 | 위치 | 개인 원격 | 작업 브랜치 | 함께 검증한 하위 커밋 |
| --- | --- | --- | --- | --- |
| 상위 프로젝트 | `.` | https://github.com/blurblah/eink-pop | `main` | 해당 없음 |
| 게임 | `repos/SDLPoP` | https://github.com/blurblah/SDLPoP | `eink-pop` | `ea22c44100278f86e8b9a439bdd6a4bf673f9936` |
| 고속 드라이버 | `repos/EPD_Painter` | https://github.com/blurblah/EPD_Painter | `eink-pop` | `ffeea2a5db248e57f0c7ff5a1c5852b09965d586` |
| 제조사 드라이버 | `repos/LilyGo-EPD47` | https://github.com/blurblah/LilyGo-EPD47 | `eink-pop` | `9b8dcdba04ed03ee70dba412667803b1dac1adfd` |

위 커밋은 기존 Mac·ESP32 검증의 소스 기준이며 Pi 빌드·실행 성공을 의미하지 않는다. 각 브랜치가 진전돼도 과거 검증 커밋은 자동으로 바꾸지 않는다. 새 조합 검증 후 커밋과 결과를 함께 기록한다.

상위 저장소는 위 세 경로를 `.gitignore`로 제외한다. `.gitmodules`와 gitlink는 없다. 각 폴더 내부의 `.git/`가 이력과 설정을 보관하며 상위 `.git/modules/`에 의존하지 않는다. 상위의 별도 worktree마다 독립 저장소가 자동으로 복제되는 것은 아니다.

## 새 환경에서 받기

```sh
git clone https://github.com/blurblah/eink-pop.git
cd eink-pop
mkdir -p repos
git clone -b eink-pop https://github.com/blurblah/SDLPoP.git repos/SDLPoP
git clone -b eink-pop https://github.com/blurblah/EPD_Painter.git repos/EPD_Painter
git clone -b eink-pop https://github.com/blurblah/LilyGo-EPD47.git repos/LilyGo-EPD47
```

명령은 브랜치 최신 상태를 받는다. 위 표의 검증 버전을 정확히 재현할 때는 새 복제본에서 해당 커밋으로 별도 브랜치를 만들어 사용한다. 작업 중인 저장소의 변경을 reset·checkout으로 덮어쓰지 않는다. `git submodule update`는 사용하지 않는다.

## 로컬 원격과 개발

기존 Mac의 세 독립 저장소는 `origin`을 개인 fork의 SSH 주소, `upstream`을 원래 공식 주소로 설정한다. 새 HTTPS clone에서 push하려면 GitHub 인증을 설정하거나 SSH 키가 준비된 환경에서 origin URL을 SSH로 바꾼다. Mac에서 Pi로 접속하는 authorized_keys 설정은 Pi에서 GitHub로 접속할 인증과 별개다.

| 저장소 | upstream |
| --- | --- |
| SDLPoP | https://github.com/NagyD/SDLPoP.git |
| EPD_Painter | https://github.com/tonywestonuk/EPD_Painter.git |
| LilyGo-EPD47 | https://github.com/Xinyuan-LilyGO/LilyGo-EPD47.git |

예를 들어 SDLPoP 작업은 다음 위치에서 한다.

```sh
cd repos/SDLPoP
git status
git add <수정한-파일>
git commit -m "변경 설명"
git push origin eink-pop
```

상위 프로젝트에는 하위 저장소 경로를 다시 git add하지 않는다. 상위 호스트·펌웨어·문서 변경은 상위에서 별도로 커밋한다. 호스트와 드라이버 코드가 참조하는 상대 경로, `--library "$PWD/repos/EPD_Painter"` 같은 빌드 경로는 유지한다.

## 이전 이력과 보존

- 전환 전 구성은 상위 커밋 `cded7cc`에 보존돼 있다. 당시 submodule 기록은 역사적 상태이며 현재 작업 방법이 아니다.
- `/Users/blurblah/workspace/SDLPoP`는 이관 전 원본으로 그대로 남긴다. 기존 `src/common.h`의 `<strings.h>` 변경은 새 저장소의 `bbf16fc`와 그 후속 커밋에 이미 포함돼 있다.
- 기존 `.local/libraries/LilyGo-EPD47`, 펌웨어 백업, 시험 로그·바이너리는 변경하지 않는다.
- 로컬 전환은 Git 메타데이터를 복사하고 `.git` 포인터를 자체 디렉터리로 바꾼다. 기존 `.git/modules/repos/`는 복구용으로 남긴다. 포인터·설정·전후 파일 해시와 커밋 기록은 무시된 `artifacts/git-separation-20261010-0129/`에 보관한다.
- 세 fork의 수정 브랜치는 `codex/eink-pop`에서 `eink-pop`으로 변경한다. 새 원격 브랜치의 SHA가 동일함을 확인한 뒤 기존 이름을 제거한다. 원본 기본 브랜치는 유지한다.
