# PoP 게임기 보드 제작 작업 인계

2026-10-09 사용자는 화면 개선은 기존 채팅에 남기고, 별도 채팅에서 보드 제작을 시도하기로 했다. 이 문서는 두 작업의 경계와 구현 기준을 전달한다.

## 현재 구성과 확인된 기준

- Mac이 SDLPoP 실행·키 입력·오디오·RGB→4명도 변환을 담당한다. USB로 최신 화면을 ESP32-S3 보드에 전달하고 ESP32가 전자종이를 구동한다.
- 실물 표기는 `Screen-4.7-S3 V2.4 2024-12-03`, 드라이버 구성은 H716이다. T5 Pro 등 다른 리비전의 핀맵과 혼용하지 않는다.
- 현재 선택한 표시 기준C: 기본톤·NORMAL 원래 직접 전이 표(내용에 따라13~19주사)·2ms·방/컷신 전환 정리.320×200 원본/640×400 표시 영역/4명도/2bpp, v9 USB 압축 전송.
- 정지 후 정리되는 것은 마지막 전체정리 후 약30초의 주기 정리다. 방/컷신 전환 때도 정리한다. 일반 변경 화면 ACK 간격은 제한된 고정 입력에서 약161ms이며 게임FPS·광학 응답·입력지연을 뜻하지 않는다.
- 사용자 확인으로 전체 정리 후에는 자국이 깨끗해진다. 주기 정리 전후 목표 픽셀도99.87~99.90% 동일하여, 표시할 그림을 바꾸는 것만의 문제로 보지 않는다. 다리와 회색 벽 등 이동 경로에 짙은 회색 자국이 남는다. 붕괴한 바닥 주변 벽면 선도 미해결이다. 표시 품질이 완성됐다고 가정하지 않는다. 패널 구동 개선은 기존 화면 작업의 범위다.

## 별도 보드 작업에서 할 일

휴대용 PoP 실행·입력·전원 구성을 구체화한다. 사용자가 말한 “보드 제작”이 기성 실행 보드 조합/프로토타입인지, 커스텀 PCB 제작까지인지 먼저 구분한다. Mac 대체 실행부·버튼·오디오·배터리/전원·디스플레이 연결의 요구조건과 단계별 계획을 만든다. 예산/크기/사용시간/보유부품은 정해졌다고 가정하지 않는다. 부품/호환성은 제조사 공식 자료로 확인하며 사용자 승인 없이 구매·PCB 발주하지 않는다.

소형 화면/휴대용이 우선이며 모니터는 비교용이라는 기존 선호가 있다. 게임 실행부를 바꾸면 입력·통신 구성은 달라지지만 패널 잔상/광학 전이 문제까지 자동 해결되는 것은 아니다.
