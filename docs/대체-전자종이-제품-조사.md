# PoP용 소형 전자종이 대체 제품 조사

조사일: 2026-10-05. 사용자 조건: 휴대용 게임기에 넣을 소형 화면 우선, 완제품 모니터는 비교용. 가성비를 고려하되 반응속도·이동 자국·화질을 함께 만족해야 한다. 기존 H716 추가 시험이나 구매는 이번 요청에 포함하지 않는다.

## 판정 기준

광고의 갱신률, 컨트롤러 처리 시간, 화면의 실제 광학 응답은 구분한다. 정지 사진·흑백 실루엣 동영상만으로 PoP의 어두운 배경, 인물 계조, 이동 자국, 전투 조작감을 검증했다고 하지 않는다. 같은 생산 모델과 구동 모드로 실제 게임을 실행한 근거가 필요하다. 이 조사에서 직접 실물을 측정하지 않았다.

현재까지 확인한 자료로는 요구 조건을 충족했다고 검증된 소형 e-ink 제품을 추천할 수 없다. Modos 6인치는 기술적 검토 우선 후보이며 구매 권고와는 구분한다. Aside에서도 실사용 근거를 조사했으며 결론은 같다. 아래에 실제 확인 범위와 한계를 기록했다.

## e-ink 밖의 방향

반사형 LCD/Memory LCD는 e-ink와 다른 표시 기술이므로 e-ink 요구를 충족하는 제품처럼 추천하지 않는다. 사용자가 전자종이 방식 자체보다 반사형·비발광 화면에서의 게임 플레이를 우선할 때 별도 검토할 방향이다.

Playdate의 PoP 포트는 발견했지만 작성자가 미완성·버그 많음이라고 명시하므로 완성된 PoP 게임기 대안으로 추천하지 않는다. [포트 작성자 페이지](https://m4rvin.itch.io/prince-of-persia)

## 구매 전 필요한 근거

다시 구매 후 드라이버 연구로 돌아가는 상황을 피하려면, 후보 제조사 또는 기존 사용자가 해당 생산 모델로 PoP의 달리기·점프·전투·방 전환을 연속 실행한 원본 촬영을 확보하는 편이 낫다. 전체 지우기 빈도, 검정 배경의 이동 흔적, 인물 명암, 입력→움직임 지연을 같이 확인해야 한다. 판매자에게 문의를 보내거나 영상 제작을 요청하는 행위는 이번 조사에서 수행하지 않는다.

## 최종 권고

1. **지금 교체 구매할 제품은 추천하지 않는다.** 충분히 빠르면서 잔상·명암이 문제없다는 소형 PoP 실사용 근거를 확보하지 못했다.
2. e-ink를 유지한다면 Modos6을 검증 우선 대상으로 남긴다. $267(본체+표시 국제배송)부터 시작하고 게임 호스트·전원·케이스·수입비용이 더 필요한 개발키트다. 구매하면 확실히 해결되는 대체품으로 소개하지 않는다.
3. 사용자 의도가 추가 연구가 아닌 안정적인 게임 플레이면, 반사형 LCD/Memory LCD로 요구를 바꿀 수 있는지를 별도로 판단하는 편이 타당하다. 이것은 기술 방향 제안이며 특정 패널/완제품의 선정·호환성·화질을 이번에 검증한 것은 아니다.
4. 이 조사에서는 구매·문의발송·장치 재가동·코드 변경을 하지 않았다. 기존 H716 성능 개선 반복은 중단 상태를 유지한다.

Aside가 새 조사 탭을 닫았다고 보고했고, 별도 탭 목록 조회에서도 기존 사용자 탭3개만 남고 연결된 조사 탭0개임을 확인했다. CLI의 로컬 데몬은 실행 중이 아니었으나 제공된 Aside MCP 연결을 통해 조사와 탭 확인을 수행했다.
